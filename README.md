# TRABAJO-FINAL
1- TRABAJO FINAL INTEGRADOR

Con este trabajo se trata de tener a disposición los datos de los distintos Alojamientos Turisticos en la Provincia de Mendoza, en este caso con los prestadores que se encontraban habilitados en el año 2019, identificados por rubros y localidades, con sus respectivos telefonos.

2- ORIGEN DE LOS DATOS

Los datos fueron descargados de la Dataset "Datos abiertos de Mendoza", en el siguiente link: https://datosabiertos.mendoza.gov.ar/dataset/alojamientos-turisticos-habilitados

3- ESTRUCTURA DEL PROYECTO

El proyecto se ha organizado siguiendo las buenas prácticas de desarrollo y control de versiones, estructurado de la siguiente manera:

*   **`data/`**: Contiene la base de dato y archivos `.csv` utilizados en el análisis.
*   **`src/`**: Scripts de código fuente en Python (`.py`) .
*   **`readme.md`**: Este archivo, que contiene la documentación general y guía de uso del proyecto.


4- USO DE LA IA

Para realizar este trabajo se consultaron diferentes IA.
Gemini: se consulto generalmente para el uso en SQL por ej. para eliminar un rubro.
Copilot: se uso en Python por ej. pasar saber porque devolvió una columna con NaN, como renombrar una columna.
